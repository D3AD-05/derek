### Answer Types

Derek supports the following answer types:

| Answer Type                    | Description                                                                                                                               |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Scored - Single Choice**     | Participants select one answer. Points are awarded based on the score configured for the selected option.                                 |
| **Scored - Multiple Choice**   | Participants can select multiple answers. Points are awarded according to the scoring configured for each selected option.                |
| **Unscored - Single Choice**   | Participants select one answer. Responses are recorded but do not affect scores or rankings.                                              |
| **Unscored - Multiple Choice** | Participants can select multiple answers. Responses are recorded but do not affect scores or rankings.                                    |
| **Text Response**              | Participants enter a free-form response, such as feedback, comments, or descriptive answers. Text responses are not automatically scored. |

> **Note:** For scored questions, individual answer options can be assigned different scores. This allows full credit for correct answers and partial credit for partially correct answers.
